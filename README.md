# 📖 About

**DevMath** is a lightweight Python library that provides hundreds of reusable mathematical functions for everyday programming.

Whether you're building a calculator, automation script, data analysis tool, educational project, or AI application, DevMath helps you perform mathematical operations with clean and simple code.

# 📚 Usage Examples

## 🔢 Arithmetic

```python
import devmath.arithmetic as arithmetic

print(arithmetic.add(10,5))
print(arithmetic.subtract(10,5))
print(arithmetic.multiply(10,5))
print(arithmetic.divide(10,5))
```

---

## 📐 Geometry

```python
import devmath.geometry as geometry

print(geometry.area_circle(10))
print(geometry.area_rectangle(20,10))
print(geometry.volume_sphere(8))
```

---

## 📈 Algebra

```python
import devmath.algebra as algebra

print(algebra.solve_linear(2,10))
print(algebra.solve_quadratic(1,-5,6))
```

---

## 📊 Statistics

```python
import devmath.statistics as stats

numbers=[10,20,30,40,50]

print(stats.mean(numbers))
print(stats.standard_deviation(numbers))
```

---

## 🔢 Number Theory

```python
import devmath.number as number

print(number.is_prime(97))
print(number.gcd(24,18))
print(number.lcm(24,18))
```

---

## 📐 Matrix

```python
import devmath.matrix as matrix

A=[[1,2],[3,4]]
B=[[5,6],[7,8]]

print(matrix.add(A,B))
print(matrix.multiply(A,B))
```
